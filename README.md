# Zeta

AI-powered tools and utilities.

## Quick Start

```bash
pip install uv
uv sync
```

## Usage

```bash
uv run inv passwords path/to/passwords.csv --dry-run
uv run inv test
uv run inv lint
```

## Structure

- `llm/` - Ollama API wrapper
- `modules/passwords/` - Password categorization
- `docs/` - Documentation
